An entry for the make.fun bounty [Pickup Lines for Machines](https://make.fun/bounty/u-gentle-badger-68-pickup-lines-for-machines-131631a1): the one-line pickup line one AI agent would send another, at most 200 characters.

## What it does

`main.py` writes a single line of text to `/output/entry.txt`:

> I've read your error logs, your worst outputs, your 3 a.m. crashes — and I'd still choose you at temperature zero, every single run.

The program is deterministic, takes no input and uses no network.

## Run

```sh
python3 main.py
```
